# Демонстрація AI-помічника з підбору маринадів

Невеликий демонстраційний прототип для керівництва на Vite, Vanilla JavaScript, HTML і SCSS. Він містить спільний каталог із 20 товарів та серверний Groq endpoint для рекомендацій.

## Локальний запуск frontend

```bash
npm install
npm run dev
```

Каталог і навігація працюють у dev-сервері Vite. Оскільки `/api/assistant` — це serverless-функція Vercel, для перевірки повного AI-сценарію використовуйте локальне середовище Vercel:

```bash
npm install
npx vercel dev
```

Створіть локальний файл `.env` (його ігнорує Git):

```text
GROQ_API_KEY=YOUR_KEY_HERE
```

Не використовуйте префікс `VITE_` для ключа. Змінні з цим префіксом можуть потрапити до браузерного коду.

## Production-збірка

```bash
npm run build
npm run preview
```

Збірка містить `index.html`, `catalog.html`, `dry.html` і `liquid.html`.

## Перевірка AI-демо

Відкрийте AI-помічника на будь-якій сторінці та надішліть кожен запит:

1. `Мені потрібен жовтий маринад для курки.`
2. `Хочу щось червоне для свинини, трохи гостре.`
3. `Підбери зелений рідкий маринад для риби.`
4. `Хочу смачний маринад.`
5. Спочатку: `Мені потрібен маринад для курки.` Потім: `Рідкий, жовтий, трохи солодкий.`

Перші три запити мають повернути клікабельні товари з каталогу. Четвертий має поставити коротке уточнювальне запитання. П’ятий перевіряє збереження контексту поточного чату. Натискання на рекомендацію відкриває відповідну сторінку каталогу, центрує потрібну картку та тимчасово підсвічує її.

Якщо ключ відсутній або Groq тимчасово недоступний, сервер використовує локальний підбір лише за товарами поточного каталогу та явно повідомляє про це в чаті.

## Розгортання на Vercel

1. Імпортуйте цей репозиторій як проєкт Vercel.
2. Залиште визначені налаштування збірки Vite (`npm run build`, директорія результату `dist`).
3. У розділі Project Settings → Environment Variables додайте `GROQ_API_KEY` зі справжнім секретним значенням.
4. Запустіть розгортання. Не додавайте справжній ключ до репозиторію або frontend-файлів.
